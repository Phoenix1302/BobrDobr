# История изменений (Changelog) BobrDobr VPN

Все заметные изменения в проекте документируются в этом файле.

---

## [1.1.1] - 2026-11-05

### Добавлено и оптимизировано
- **Динамическая ротация пула адаптеров Wintun (`awg0` ↔ `awg1` ↔ `awg2`)**:
  - Устранена гонка драйвера Wintun PnP (`Timed out waiting for device query (Code 0x00000102)` и `Failed to setup adapter (problem code: 0x1F, ntstatus: 0xC0000001): Присоединенное к системе устройство не работает`).
  - При переподключении или быстром переключении между профилями система проверяет реестр `SWD\\WINTUN` и сетевой стек Windows, циклически переключаясь на свободный адаптер. Новый туннель инициализируется параллельно и мгновенно, не блокируясь ожиданием фоновой разрегистрации предыдущего сетевого устройства в ОС.
  - Таймаут корректного отключения в `shutdown_worker` увеличен до 6.0 с для безопасного освобождения ресурсов драйвером `amneziawg-go.exe`.
- **Интеграция быстрого перехода в «Личный кабинет»**:
  - Автоматическое и динамическое извлечение корневого домена из ссылки токена подписки (`get_cabinet_url`, например `https://persona.netphoenix.ru`).
  - Добавлены кнопки быстрого перехода в браузер «🌐 Личный кабинет ↗»:
    - В верхней панели действий главного окна (рядом с кнопкой «✨ Подписка»).
    - В стартовом информационном баннере («Продлить в личном кабинете ↗» / «Открыть личный кабинет ↗»).
    - В диалоге управления подпиской (`SubscriptionManageDialog`).
    - В модальных диалогах карточек подключений при попытке запуска заблокированного или истекшего профиля.
- **Бесшовная активация уже запущенного экземпляра (Single-Instance Restoration)**:
  - Сервер `QLocalServer` теперь запускается в самом начале жизненного цикла `MainWindow` с флагом `WorldAccessOption`, обеспечивая надёжную доставку сигнала `ACTIVATE` даже между разноуровневыми процессами Windows.
  - Устранён вызов `AttachThreadInput` к чужому окну переднего плана (браузеру или IDE), приводивший к мерцанию и перехвату чужих событий ввода.
  - Внедрён вызов `AllowSetForegroundWindow(0xFFFFFFFF)` и безопасная передача фокуса через имитацию Alt-key (`keybd_event(VK_MENU)`), гарантирующая мгновенный вывод окна BobrDobr на передний план даже из скрытого состояния в трее без навязчивого блокирующего диалога.
  - Добавлена строгая фильтрация процессов через `QueryFullProcessImageNameW` (исключены процессы браузеров, проводника и сред разработки).
- **Корректное завершение AmneziaWG и сброс сетевых маршрутов Wintun**:
  - Внедрена передача консольного сигнала `CTRL_BREAK_EVENT` для runtime Go в Windows, позволяющая `amneziawg-go.exe` штатно очистить виртуальный адаптер Wintun и восстановить системную таблицу маршрутов `0.0.0.0/0`.
  - Устранено исключение `[WinError 6] Неверный дескриптор` в `shutdown_worker` при повторном вызове `wait()` на уже завершенном процессе.
- **Штатное отключение OpenConnect (AnyConnect BYE)**:
  - Доставка сигналов консоли Windows обеспечивает отправку серверу ocserv официального пакета `BYE` и корректное закрытие сессии (`invalidating session of user`) без ошибок `unspecified error`.
- **Устранение критической ошибки запуска (`QSizePolicy`)**:
  - Исправлен импорт `QSizePolicy` в `src/gui/profile_card.py`.
- **Редизайн и модернизация визуального оформления UI**:
  - Высокотехнологичные темные градиенты, полупрозрачные неоновые ауры состояния карточек и аккуратные бейджи статуса.

## [1.1.0] - 2026-11-04

### Добавлено и оптимизировано
- **Механизм управления и синхронизации подписок (BobrDobr VPN)**:
  - Реализован централизованный импорт всех доступных подключений пользователя (AmneziaWG и OpenConnect) по персональной ссылке подписки `https://{host}/api/v1/sub/{TOKEN}`.
  - В диалоге создания подключений добавлен протокол «Подписка (BobrDobr VPN)» с интерактивной проверкой ссылки, валидацией статуса, выводом данных аккаунта и предпросмотром доступных соединений.
  - Кнопка «📋 Вставить» с мгновенной проверкой ссылки из буфера обмена.
  - Детализированная обработка ошибок HTTP с понятными сообщениями на русском языке (401 недействительный токен, 403 блокировка/истечение срока действия, 429 ограничение частоты запросов с экспоненциальным откатом, сетевой таймаут).
- **Диалог управления подпиской (`SubscriptionManageDialog`)**:
  - Выделенная кнопка «✨ Подписка» в панели действий главного окна.
  - Окно детальной информации: отображение срока окончания (включая точный таймер дней/часов), шлюза плотины, списка связанных профилей, кнопки ручной синхронизации и безопасного удаления подписки без затрагивания ручных профилей.
- **Эффект «заморозки» и защитные блокировки (`Frozen Profiles`)**:
  - При блокировке администратором, истечении срока подписки или временной заморозке карточки подключений автоматически переходят в стильный «морозный» режим (`CARD_STYLE_FROZEN`) с неоновым свечением и бейджами `⛔ заблокировано`, `⌛ истекла` или `❄ заморожено`.
  - Кнопка подключения блокирует попытку запуска недоступного туннеля и выводит модальное окно с разъяснением и рекомендацией по продлению/разблокировке в личном кабинете.
- **Стартовые информационные баннеры (`Announcement Banner`)**:
  - Адаптивный верхний баннер на главном экране при запуске:
    - Предупреждение о скором окончании подписки (≤ 3 дней) с расчётом оставшегося времени и возможностью закрытия.
    - Уведомления об истечении срока действия подписки или блокировке администратором со ссылкой на меню подписки.
- **Визуальная индикация и нормализация названий**:
  - Автоматическое добавление суффикса `-sub` (строчными буквами, слитно без пробела) к именам подписных подключений.
  - Векторный значок и фиолетовый бейдж `SUB` на карточках подключений.
  - Автоматическая нормализация существующих названий профилей при загрузке.
- **Поддержка камуфляжа OpenConnect (Camouflage Secret Query)**:
  - Нормализация пути маскировки к формату `/?{secret}` (`https://host:443/?secret`), устраняющая ошибки `405 Not Allowed` при обращении к скрытым точкам входа OpenConnect.
- **Устранение падений при переподключении и защита от гонок процессов (Reconnect Race Safety)**:
  - **Безопасная обработка консольных сигналов Windows**: устранено аварийное завершение процесса Python (`STATUS_CONTROL_C_EXIT`) при отключении туннелей. Вызов `SetConsoleCtrlHandler(None, True)` теперь удерживается постоянно и никогда не сбрасывается в `False`, защищая GUI-процесс от асинхронно доставляемых сигналов `CTRL_C_EVENT`.
  - **Синхронное ожидание завершения предыдущего процесса**: в `VPNLauncherBase.start_connection()` и `_spawn_process()` добавлено синхронное ожидание (`stop_connection(wait=True)`), если старый процесс ещё завершается или находится в состоянии `DISCONNECTING`, исключая конфликты сетевых адаптеров Wintun/TUN.
  - **Защита ссылок на процесс в `shutdown_worker` и `_monitor_exit`**: очистка `self._process = None` производится только в том случае, если ссылка указывает именно на завершаемый процесс, предотвращая затирание нового экземпляра при быстром переподключении.
  - **Предохранитель фонового таймера зачистки**: фоновый `cleanup_worker` с таймером в `OpenConnectLauncher` и `AmneziaWGLauncher` проверяет токен сессии (`_session_run_id`) и состояние `CONNECTING/CONNECTED`, предотвращая убийство вновь запущенного соединения.
  - **Единый мьютекс изоляции экземпляров**: объединён глобальный мьютекс (`Global\BobrDobr_VPN_SingleInstance_Unified_v1`), исключающий одновременный запуск установленной и portable-версий программы.
  - **Защита интерфейса карточки профиля**: кнопка переключения блокируется (`setEnabled(False)`) на всё время нахождения в состоянии `DISCONNECTING`, предотвращая повторные клики до перехода в `DISCONNECTED` или `ERROR`. Добавлено свойство `state` в `VPNProfileCard` и устранена ошибка `AttributeError` в слоте `_on_state_change`.
- **Штатное завершение OpenConnect (AnyConnect BYE / CSTP Logout)**:
  - Устранена ошибка жесткого завершения процесса (`TerminateProcess`) при отключении: клиент теперь отправляет штатный сигнал в консоль и даёт OpenConnect время для передачи пакета завершения сеанса (AnyConnect BYE packet) серверу ocserv и деконфигурации маршрутов через `vpnc-script`.
  - Устранены записи `sec-mod: temporarily closing session` и `user disconnected (reason: unspecified error)` в системном журнале сервера.
- **Единый мьютекс и защита от одновременного запуска (Unified Single-Instance)**:
  - Внедрён единый глобальный мьютекс `Global\BobrDobr_VPN_SingleInstance_Unified_v1` для предотвращения параллельного запуска Installed и Portable версий.
  - При попытке запуска дублирующего экземпляра приложение активирует и выводит на передний план окно уже работающего клиента, показывает системное уведомление и завершает дубликат с кодом 0.
  - Поддержка обратной совместимости с устаревшими именами мьютексов.
- **Изоляция процессов демонов и предохранение сетевого адаптера Wintun**:
  - Точечное завершение только зависших процессов текущего приложения (`get_bobrdobr_daemon_pids`): исключено случайное закрытие сторонних VPN-клиентов на ПК пользователя.
  - Предохранительный механизм `prepare_tunnel_adapter`: проверка доступности адаптера перед стартом, очистка фантомных устройств Wintun и автоматический переход на свободный адаптер (`awg1`..`awg9`) при занятости `awg0`.
  - Устранены гонки при быстром переподключении: проверка токенов сессий (`_session_run_id`) исключает уничтожение нового туннеля фоновым обработчиком старого отключения.
- **Атомарное сохранение и защита настроек от повреждений**:
  - Сохранение `settings.json` и `settings_portable.json` через временный файл с атомарной заменой (`os.replace`) и синхронизацией буферов (`fsync`).
  - Автоматическое создание резервных копий (`.bak`) и восстановление конфигураций при аварийных сбоях.
- **Исправления стабильности и сборки**:
  - Устранена потенциальная циклическая зависимость в пакете `core/__init__.py` для сборщика PyInstaller.
  - Исправлен импорт `QSizePolicy` в модуле карточки профиля.

## [1.0.13] - 2026-10-24

### Безопасность и оптимизация хранилища
- **Устранение утечек открытых данных и дублирования конфигураций**:
  - Проведён комплексный аудит структуры сохранения `settings.json` и `settings_portable.json`.
  - Устранено дублирование незашифрованных параметров AmneziaWG (`endpoint`, `address`, `dns`, `allowed_ips`, `obfuscation`, `config_path`): на диске сохраняется исключительно криптографически защищённый блок `config_content` и технические метаданные (`id`, `name`, `proto`, `interface`).
  - Все необходимые поля профиля (`endpoint`, `address`, `dns`, `allowed_ips`, `obfuscation`) динамически восстанавливаются и парсятся в оперативной памяти при загрузке, обеспечивая полноценную работу интерфейса и туннелей без утечки на диск.
  - Исключена утечка локальных пользовательских путей (`config_path`) в открытом виде.
- **Шифрование чувствительных параметров OpenConnect**:
  - Адрес шлюза плотины (`server`), токен маскировки (`camouflage`) и логин пользователя (`username`) теперь шифруются на диске нативными средствами Windows DPAPI (или машинным ключом в Portable) наравне с паролем доступа.
  - В открытом виде остаются только технические сетевые параметры (`port`, `proto`, `protocol`, `remember_password`).
  - Глобальные параметры OpenConnect (`openconnect_server`, `openconnect_camouflage_secret`, `openconnect_user`, `openconnect_password`) также шифруются на диске.
- **Бесшовная миграция и очистка резервных копий**:
  - Обеспечена 100% обратная совместимость: существующие файлы настроек прозрачно считываются и автоматически перезаписываются в защищённом формате при первом старте.
  - В каталоге `%APPDATA%\BobrDobr\backups\` активирована автоматическая ротация резервных копий с сохранением только 3 наиболее актуальных копий.

## [1.0.12] - 2026-10-23

### Добавлено и оптимизировано
- **Постоянное хранение файлов в установленном режиме (устранение задержки запуска на HDD)**:
  - Решена проблема медленного старта приложения на накопителях с невысокой скоростью произвольного доступа (HDD):
    - В **установленном режиме (Installed)** все файлы среды выполнения (`python311.dll`, `base_library.zip`, `PySide6`, библиотеки, бинарники и ресурсы) теперь размещаются постоянно в каталоге `%LOCALAPPDATA%\Programs\BobrDobr\`.
    - Исполняемый файл установленной версии запускается напрямую без распаковки во временный каталог `%TEMP%\_MEIxxxxxx`, что обеспечивает мгновенный холодный и горячий запуск.
    - В **портативном режиме (Portable)** сохранена концепция единого переносимого `.exe`-файла с распаковкой в `%TEMP%`.
  - Реализован двухэтапный гибридный механизм сборки в `BobrDobr-VPN.spec`:
    - Генерируется нативный direct-exec лончер `BobrDobr-Installed.exe` (`contents_directory='.'`, `exclude_binaries=True`), который упаковывается внутрь основного переносимого исполняемого файла релиза.
    - При установке или обновлении лончер и распакованные компоненты среды безопасно разворачиваются в постоянный каталог установки.
    - Сохраняется резервная копия переносимого бинарника для прозрачного возврата к Portable-режиму через `revert_to_portable()`.
- **Устранение дублирования бинарников и папки-призрака на диске**:
  - В установленном режиме исключено дублирование VPN-утилит (`amneziawg-go`, `wintun.dll`, `openconnect`): служба использует постоянную директорию `%LOCALAPPDATA%\Programs\BobrDobr\bin\windows\`.
  - Устаревший кэш и папка-призрак `%LOCALAPPDATA%\BobrDobr\` автоматически полностью удаляются при установке, обновлении и старте установленной версии.
  - Для переносимого режима сохранена изолированная постоянная директория кэша `%LOCALAPPDATA%\BobrDobr\bin\` для стабильности правил Брандмауэра Windows.

## [1.0.11] - 2026-10-18

### Добавлено и оптимизировано
- **Мгновенный старт подключения AmneziaWG (0 мс задержки)**:
  - Устранена безусловная блокирующая задержка перед стартом AmneziaWG (~1.1–1.4 секунды), вызывавшаяся процессами `powershell.exe` (`Get-NetAdapter`, `Get-PnpDevice`, `pnputil`) и `taskkill.exe`.
  - Внедрены ультрабыстрые нативные Win32 API проверки в памяти:
    - `is_process_running`: проверка активных процессов через `CreateToolhelp32Snapshot` (~0.2 мс).
    - `get_wintun_device_instances`: мгновенное обнаружение фантомных узлов PnP Wintun (`SWD\WINTUN\{...}`) через реестр `winreg` (<0.1 мс).
    - `is_network_adapter_present`: проверка наличия сетевого адаптера через системный вызов `ConvertInterfaceNameToLuidW` (`iphlpapi.dll`) (~0.001 мс).
  - В штатном режиме зачистка и паузы полностью пропускаются — процесс запускается немедленно (0 мс задержки).
  - При наличии остаточных адаптеров в PnP зачистка выполняется напрямую через `pnputil.exe /remove-device ... /subtree` за ~20 мс без запуска медленного PowerShell.
  - Добавлено автовосстановление в лог-парсере: при ошибках создания адаптера (`Cannot create a file when that file already exists`, тайм-аут запроса устройства) выполняется немедленная зачистка фантомного PnP-узла.
- **Корректный подсчёт профилей в окне обновления**:
  - В `UpdateDialog` количество переносимых конфигураций (`get_migratable_profiles_count`) теперь корректно считывается из профилей установленной версии (`settings.json`), а не из пустого портативного хранилища.
- **Упрощение диалога обновления**:
  - Из `UpdateDialog` удалена избыточная кнопка «Удалить с ПК», исключая случайное удаление при обновлении. Управление установкой и деинсталляция доступны через специализированный диалог управления.
- **Редизайн векторных бейджей протоколов**:
  - **AmneziaWG**: круг с фирменным шевроном «W» в теплых янтарно-оранжевых тонах (`#f59e0b` / `#fbbf24`) с градиентным свечением.
  - **OpenConnect**: стилизованный векторный купол защитного шлюза в ярких бирюзово-голубых тонах (`#22d3ee`).
  - Значки гармонично интегрированы в карточки подключений (`ProfileCard`) и выпадающий список выбора протокола (`ProfileDialog`).

## [1.0.9] - 2026-10-17

### Добавлено и исправлено
- **Разделение конфигураций Portable и Installed**:
  - Установленная версия использует основной файл конфигурации `settings.json`.
  - Портативная версия использует изолированный файл `settings_portable.json`, предотвращая конфликты настроек между версиями на одном ПК.
