# Linux Native Binaries

Поместите сюда исполняемые файлы для Linux x86_64:

- `amneziawg-go` — скомпилированный бинарник amneziawg-go.
- `awg-quick` — bash-скрипт или бинарная утилита управления интерфейсом WireGuard/Amnezia.
- `openconnect` — автономный или системный исполняемый файл OpenConnect.
- `vpnc-script` — стандартный vpnc-скрипт настройки маршрутов для Linux.

Лаунчер проверяет наличие файлов сначала в `bin/linux/` (или рядом с бинарником приложения), а затем в системном `$PATH`.
Для работы с сетевыми интерфейсами (TUN) в Linux приложению могут потребоваться права суперпользователя (`sudo` / `pkexec` / `setcap cap_net_admin+ep`).
