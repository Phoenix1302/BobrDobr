# БобрДобр VPN (AmneziaWG & OpenConnect Network Client)

Кроссплатформенный (Windows & Linux) настольный графический клиент для защищённых сетевых туннелей и удалённого доступа к частным и корпоративным сетям на базе современных протоколов:
- **AmneziaWG / WireGuard** (высокопроизводительный туннель с поддержкой расширенных параметров заголовков пакетов: `Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1-H4`)
- **OpenConnect** (SSL VPN клиент, совместимый с Cisco AnyConnect, Pulse Connect Secure, GlobalProtect, Juniper, F5 BIG-IP, Fortinet)

---

## 🛡️ Архитектура и ключевые возможности

1. **Безопасная работа с процессами ядра**:
   - `amneziawg-go.exe`: автономный сетевой сервис туннелирования.
   - `wintun.dll`: высокопроизводительный драйвер виртуального сетевого адаптера Wintun x64.
   - `openconnect.exe`: полнофункциональный SSL VPN клиент с комплектом криптографических библиотек (GnuTLS, Nettle, GMP).
   - `vpnc-script-win.js`: автоматическое конфигурирование сетевых маршрутов и DNS.

2. **Безопасность учётных данных**:
   - Пароли для соединений передаются через защищённый ввод (stdin pipe процесса) и не отображаются в списке аргументов командной строки (`cmdline` / Диспетчер задач).
   - Поддержка шифрования сохранённых профилей с использованием защищённого системного хранилища.

3. **Чистое обновление и миграция профилей**:
   - Встроенный механизм бесшовного обновления: автоматическое обнаружение установленной версии, безопасный перенос профилей подключений и сброс системных настроек к дефолтным для предотвращения конфликтов между версиями.

4. **Корректное завершение и освобождение ресурсов**:
   - Сетевые сервисы изолированы в выделенных группах процессов (`CREATE_NEW_PROCESS_GROUP` / `os.setsid`).
   - При отключении или выходе из приложения лаунчер безопасно завершает сетевые службы, сбрасывает добавленные маршруты и освобождает виртуальные адаптеры.

5. **Графический интерфейс на PySide6 (Qt)**:
   - Объемный эргономичный интерфейс в темных тонах.
   - Удобное переключение профилей через системный трей.
   - Встроенный интерактивный просмотрщик сетевых логов и статуса подключения.

## 🚀 Сборка и релизы

### Автоматическая сборка (CI/CD)
Проект настроен на автоматическую сборку исполняемых файлов через **GitHub Actions**:
При создании тега версии (например, `v1.0.7`) виртуальная машина Windows автоматически собирает автономный `BobrDobr-VPN.exe` и публикует его в разделе **Releases**.

### Локальная сборка на Windows:
```powershell
pip install -r requirements.txt pyinstaller
pyinstaller BobrDobr-VPN.spec
```
Готовый исполняемый файл создаётся в директории `dist/windows/BobrDobr-VPN.exe`.
