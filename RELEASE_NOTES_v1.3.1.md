## 🇷🇺 Русский язык

### Обзор релиза BobrDobr VPN v1.3.1

В версии **v1.3.1** реализована аппаратная анимация динамической контурной подсветки карточек подключений («бегущий огонёк»), оптимизирована работа с подписками в GUI, обеспечена полная стабильность контекстного меню в области скрытых значков системного трея Windows 10 и 11, а также обновлены метаданные проекта.

---

### 🚀 Ключевые изменения (Major Highlights)

1. **Динамическая контурная анимация («Бегущая неоновая лента»)**:
   - Внедрена эффектная аппаратная анимация неоновой ленты, пробегающей по периметру карточки подключения (`conic-gradient` + CSS `@property --beam-angle`, `--beam-color`, `--beam-tail`, `--beam-spark`).
   - **Фаза согласования соединения (`Connecting`)**: пока туннель поднимается, янтарный неоновый луч непрерывно обегает контур карточки (без статической неоновой рамки вокруг).
   - **Бесшовный переход в статус `Connected`**: в момент успешного установления связи цвет бегущего луча плавно, на лету (in-flight) переходит из янтарного в изумрудно-зелёный без сброса угла вращения. Зелёный луч эффектно докручивает свой оборот до конца (360°), и в момент завершения круга мягко воспламеняется статичный зелёный неоновый ободок карточки.
   - **Нулевая нагрузка на CPU**: анимация полностью обрабатывается GPU-композитором WebView2 и никак не замедляет инициализацию адаптера Wintun и запуск VPN-соединения.

2. **Удобство работы с подписками в GUI**:
   - Кнопка **«Подписка»** в шапке при отсутствии добавленной подписки автоматически открывает модальное окно добавления подключения с фокусом на разделе подписки.
   - Поле URL в модальном окне подписки по умолчанию защищено от случайного изменения (режим «только чтение») с удобным копированием ссылки в буфер обмена по клику.
   - Добавлена кнопка редактирования ✏️ для безопасного обновления ссылки и компактная кнопка 📋.

3. **Стабильность меню в системном трее Windows 10 и 11**:
   - Контекстное меню теперь корректно удерживает окно раскрытия скрытых значков трея (`TopLevelWindowForOverflowXamlIsland` в Windows 11 и `NotifyIconOverflowWindow` в Windows 10). Панель скрытых значков остаётся открытой при перемещении курсора на пункты меню.
   - Завершение работы меню и скрытие панели трея на Windows 11 происходят нативно через аппаратные события `VK_ESCAPE` и системный страховочный таймер, устраняя зависание/замораживание XAML-островка трея Windows 11 при клике вне меню, а шеврон `^` раскрывает трей с первого нажатия.

4. **Авторство проекта в настройках**:
   - В модальное окно настроек программы добавлена стилизованная карточка разработчика с фирменным логотипом GitHub, бейджем авторства и прямой ссылкой на профиль [@Phoenix1302](https://github.com/Phoenix1302).
